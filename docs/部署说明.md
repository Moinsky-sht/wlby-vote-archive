# 北京市青年铸牢文创设计大赛 H5 投票系统部署说明

本文档不包含任何真实账号、密码或密钥。

## 一、运行环境

- Ubuntu 22.04 或更新版本
- Node.js 20 或 22
- pnpm
- PostgreSQL 16
- PM2
- Nginx
- HTTPS 证书

## 二、部署目录

项目目录：

```bash
/www/wwwroot/--H5-
```

持久化上传目录：

```bash
/www/wwwroot/--H5-/data/uploads
```

## 三、环境变量

```bash
cp .env.example .env
```

正式环境至少需要设置：

- `NODE_ENV=production`
- `DATABASE_URL`
- `APP_SECRET`
- `COOKIE_SECURE=true`（启用 HTTPS 后）
- `TRUST_PROXY=1`
- `DATA_DIR`
- `UPLOADS_DIR`
- `ASSETS_DIR`
- `CLIENT_DIR`

需要在服务器执行飞书附件导入时，还需设置：

- `LARK_ATTACHMENT_IDENTITY=user`
- `LARK_RECORD_IDENTITY=user`
- `LARK_ATTACHMENT_ALLOWED_HOSTS`（默认仅允许飞书和 Lark 官方附件域名）

并在服务器检查授权：

```bash
lark-cli auth status --json --verify
```

用户身份过期时，重新完成最小范围授权后再执行导入。附件导入失败不会写入作品数据，已生成的本地文件也会自动回滚。

`.env` 不得提交到 GitHub。

## 四、安装与构建

```bash
pnpm install --frozen-lockfile
pnpm prisma:generate
pnpm prisma:migrate:deploy
pnpm build
```

构建结果：

- `dist/client`：前端静态文件
- `dist/server`：Express 服务

## 五、初始化管理员

```bash
pnpm admin:init -- --username=your-admin --password=your-strong-password
```

管理员密码使用 bcrypt 保存，仓库中不提供默认密码。

## 六、PM2

```bash
pm2 start dist/server/index.js --name h5-vote
pm2 save
pm2 startup
```

Node 服务默认监听 `127.0.0.1:4173`，生产环境只通过 Nginx 暴露访问入口。

## 七、Nginx

项目提供 [Nginx 配置](../ops/h5-vote.nginx.conf)。应用后执行：

```bash
nginx -t
systemctl reload nginx
```

正式环境应配置 HTTPS，并将 HTTP 自动跳转到 HTTPS。

## 八、数据库备份

项目提供 [PostgreSQL 备份脚本](../ops/h5_postgres_backup.sh)。建议每天凌晨执行 `pg_dump`，并定期验证备份可以恢复。

需要备份：

- PostgreSQL 数据库
- `data/uploads`
- 生产 `.env`（加密或受控保存，不进入 Git）
